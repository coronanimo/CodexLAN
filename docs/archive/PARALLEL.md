## 数据与执行隔离

初始化使用 SQLite 在线备份读取原版应用数据库。副本保留账号密码记录、项目授权、会话绑定、设置、访问记录和恢复数据；不接管原队列，不复制登录会话。快照的业务字段和关系与预期逐项比较，不以文件哈希或只有行数相等代替正确性。

可以使用原来的账号密码登录并行版，需要单独登录。账号、权限和设置是一次性副本，之后两边修改不会自动同步。不同数据目录产生独立的 Cookie 名称，不会把原版登录顶掉。

可选的 `parallel: true` 启用实例归属策略：只有通过本实例创建、且已持久记录在 `parallel-owned-conversations.json` 的会话可以写入。当前配置为 `false`，所有已授权会话使用正常控制和发送能力；归属文件和原应用数据都保留。

原有历史使用不恢复执行的读取接口；[原生协议说明](https://learn.chatgpt.com/docs/app-server)区分了 `thread/read`/分页读取与 `thread/resume`。原任务的实时执行和控制仍在原版进行，需要新的已保存内容时点击并行版的“最新记录”。

两版仍共用 Codex 登录、额度和现有项目文件。并行版的新项目默认放在自己的目录，上传写入自己的附件目录；历史附件允许按原项目权限从原附件目录读取，删除不使用该只读来源。独立应用实例不构成文件系统或账号沙箱。

## 管理

在外部 PowerShell 中使用独立入口：

```powershell
& "$env:LOCALAPPDATA\Programs\CodexLAN-React\CodexLAN-React.ps1" -Action Status
& "$env:LOCALAPPDATA\Programs\CodexLAN-React\CodexLAN-React.ps1" -Action Log
& "$env:LOCALAPPDATA\Programs\CodexLAN-React\CodexLAN-React.ps1" -Action Stop
& "$env:LOCALAPPDATA\Programs\CodexLAN-React\CodexLAN-React.ps1" -Action Start
```

这些命令使用并行安装的清单和配置。`Stop`/`Restart` 按调用会话所属实例的数据目录检查：禁止停止自身实例，允许管理已确认独立的实例；归属不明或数据目录重合时拒绝操作。没有给并行版注册开机启动任务，原版启动项保留。

当前复用原安装中只读的 Node 可执行文件及其已有防火墙应用规则，未改防火墙。前后端代码、数据库、队列、日志与服务状态分别存放。网络代理配置复制到并行安装，管理入口仅对子进程继承，并恢复调用终端原值。
